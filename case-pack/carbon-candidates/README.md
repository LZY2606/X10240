# 案例包：碳年候选席——校准曲线、储库偏移与多峰年代证据

这是面向年代学团队的离线领域案例包（非通用表格）。叙事主线：实验室测得的
radiocarbon age 与 SynCal-1 教学曲线（合成曲线，**不是 IntCal**）、储库偏移分布和
层序关系组合，审阅日历年代候选。

## 文件
- `case.json` — 基线（原测量值和标准差、曲线版本、偏移分布、年代系统、层序约束、
  排除决定，各自带 `sourceRef`）+ 剧本化步骤 + 机器可校验的 `expect` 期望。
- `syncal1_v1.csv` / `syncal1_v2.csv` — SynCal-1 两个版本的曲线网格
  （`calBP,c14AgeBP,sigma`， knot 间距 10 年）。由 `../tools/make_curve.py` 确定性生成。
- `malformed-examples.json` — 导入层必须拒绝的格式错误样例。

## 剧本覆盖的验收情形
1. 曲线多峰：S-001 (1400±30 BP) 落在曲线摆动段，后验出现多个不相交区间。
2. 边界插值：S-004 (615±25 BP) 贴近网格边界 600 calBP，产生 `TRUNCATED_AT_BOUNDARY` 诊断。
3. 储库偏移分布：S-005 由 N(150,30) 修订为双群混合分布，后验增加峰。
4. BCE/CE 跨界：S-003 (1950±40 BP) 落在 1950 calBP 平台段，区间跨 BCE/CE。
5. 层序矛盾：C-2（L3 老于 L2）与校准结果冲突 → `CONTRADICTION`，排除 S-001 后恢复一致。
6. 曲线升版：导入 SynCal-1 v2.0 后旧结果标记 STALE 但仍可查看，重算后区间移动。
7. 并列日历区间：S-005 两个不相交区间以 `parallel` 采纳并列保留，不压成平均年。

剧本同时演示：一次参数修订（step-6）、一次只影响局部依赖的源数据改动（step-8）、
一组互相冲突的人工决定及其解决与撤销（step-10..14）。
