# 离线案例包：碳年候选席——校准曲线、储库偏移与多峰年代证据

年代学团队把实验室测得的 radiocarbon age 与校准曲线、储库偏移和层序关系组合，审阅日历年代候选。
本目录是仓库自带的领域案例包（不是通用表格），按编号顺序在「导入/案例包」页重放：

- `00-base.json` — 初始导入。五个测量（AT-1042 木炭 2440±25、AT-1055 海贝壳 1990±30、
  AT-1060 木炭 3195±25、AT-1071 炭化种子 2600±30、AT-1099 木炭 2350±40）、曲线版本
  GSB-INTCAL-LIKE 1.0、三个储库偏移分布（陆生 0±0、海洋 A 120±40、海洋 B 300±60）、
  年代系统（calBP + BCE/CE，天文纪年无 0 年）、两条层序约束、一条排除决定（AT-1099 污染），
  每条都带来源出处；并对四个未排除测量做初始校准。
- `01-param-revision.json` — 参数修订：曲线升版 1.0 → 2.0，偏移分布 OF-MAR-B 修订为 280±55。
  依赖旧曲线/旧偏移的派生结果过期但可查看。
- `02-local-source-change.json` — 局部源数据改动：AT-1055 标准差 30 → 45（实验室重测），
  只有依赖 AT-1055 的结果过期。
- `03-conflicting-decisions.json` — 争议层序 SC-3（trench B 对比，有争议）触发层序冲突，
  产生全部合法候选调整（排除任一环路约束 / 标记离群测量，均不改写测量）；
  两位审阅者对 AT-1042 同一区间给出相反的接受/否定裁定，均写入历史。

重放实际经过：曲线多峰（AT-1042）、边界插值（AT-1060 在曲线顶端截断）、储库偏移分布
（AT-1055 用 OF-MAR-A / OF-MAR-B 对比）、BCE/CE 跨界（AT-1055 区间跨过 1 BCE/CE 1）、
层序矛盾（SC-1/SC-2/SC-3 成环）、曲线升版（1.0 → 2.0）与并列日历区间（95.4% HPD 多段）。

`curves/` 内是固定版本的校准曲线文件（calBP → ¹⁴C BP，分段线性插值），
曲线内容哈希进入每次校准的参数指纹，保证固定版本下可重现。
