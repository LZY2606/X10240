# 碳年候选席：离线案例包（离线、可复制、领域专用）

本目录是「碳年候选席：校准曲线、储库偏移与多峰年代证据」的专用离线案例包，不是通用表格。
所有数值均为为教学/回归测试构造的合成材料（曲线 `LabCal2024`），单位与来源逐条标注。

- `case-v1-import.json`：初始基线。原测量值与标准差、曲线版本、偏移分布、年代系统、
  层序约束、排除决定各自带来源（`sourceRef`）。
- `case-v2-revision.json`：一次参数修订（MAR-002 的储库偏移参数修订，新版本+父版本）。
- `case-v3-local-change.json`：一次只影响局部依赖的源数据改动（曲线升版 LabCal2024b，
  变化日历年区间与部分样本重叠/不重叠，用于检验局部过期）。
- `case-v4-conflict-decision.json`：一次互相冲突的人工决定（接受「仅保留较老峰」候选，
  同时保留被否定候选与拒绝原因；可撤销）。

重放实际经过：曲线多峰、边界插值、储库偏移分布、BCE/CE 跨界、层序矛盾、曲线升版、并列日历区间。
