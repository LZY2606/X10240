# 碳年候选席 — 离线领域案例包

面向“放射性碳/年代校准/多峰分布工作台”的专用离线材料（非通用表格）。

叙事顺序（每一步都是同一项目的连续审阅，不拆成无关按钮）：

1. `00-baseline.json` — 基线：原测量值与标准差、曲线版本、偏移分布、年代系统、
   层序约束、排除决定各自登记来源；自动产生首轮校准与层序分析。
   - `S1`：1000±30 BP 落在曲线 wiggle 平台 → 曲线多峰 / 并列日历区间
   - `S2`：海相贝样 + 离散混合储库偏移
   - `S3`：1930±70 BP → 后验跨过 BCE/CE 边界（天文年 0 = 1 BCE）
   - `S4`：2075±25 BP 靠近曲线最年轻端 → 边界插值/截断诊断
   - `S5 → S6`：层序声明与校准结果矛盾 → 候选调整（不改写测量）
   - `S7`：疑似现代污染 → 排除决定（保留测量与来源）
2. `01-offset-revision.json` — 参数修订：S2 改单一高斯偏移（只让依赖它的结果过期）。
3. `02-measurement-revision.json` — 局部源数据改动：S6 复测新值作为新版本，
   父版本 `m-S6-1` 保留；层序矛盾解除，旧校准仍可查看但标记过期。
4. `03-conflicting-decisions.json` — 互相冲突的人工决定并存，随后撤销其一；
   撤销写历史，不删除事件。
5. `04-curve-bump.json` — 曲线升版 v2（父子版本），依赖曲线的结果自动重算，
   旧版本结果保留为过期；随后在复核界面上对并列日历区间做接受/否定。

机器可读事件：导入与每一步操作都进入 append-only 哈希链事件日志；回到任意旧
事件时恢复当时的依赖版本与可见结论。导出为事件流，删除本地数据库后再导入，
稳定身份、顺序与来源关系保持不变。
